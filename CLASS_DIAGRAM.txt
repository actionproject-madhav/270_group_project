│                          KEY OOP CONCEPTS                                       │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  1. ENCAPSULATION: All fields private, accessed via getters/setters            │
│     Player: private String id; public String getId()                          │
│                                                                                  │
│  2. INHERITANCE: SinglesMatch and DoublesMatch extend Match                    │
│     public class SinglesMatch extends Match { ... }                            │
│                                                                                  │
│  3. ABSTRACTION: Match is abstract class with abstract methods                 │
│     abstract class Match {                                                     │
│         public abstract boolean getWinner();                                   │
│         public abstract List<Player> getParticipants();                        │
│     }                                                                           │
│                                                                                  │
│  4. POLYMORPHISM: Single interface, multiple implementations                   │
│     List<Match> matches = new ArrayList<>();                                   │
│     matches.add(new SinglesMatch(...));  ✓                                     │
│     matches.add(new DoublesMatch(...));  ✓                                     │
│                                                                                  │
